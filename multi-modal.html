QRUM Multi-Modal Quantum Perturbation Detection Architecture

Correlation-Based Analysis of Open Gravitational-Wave Data

Author: P. Gabor (Palásti Gábor)

Publication: 28 July 2026 · Version 2

Resource type: Preprint

DOI:10.5281/zenodo.21656162

This preprint presents a reproducible correlation-based framework for the analysis of publicly available gravitational-wave observations from the Gravitational Wave Open Science Center (GWOSC).

The workflow uses synchronized detector pairs, cross-correlation, residual spectral analysis and bootstrap validation. The framework is designed around open data, transparent methodology and reproducible computational analysis.

The study is exploratory. No discovery of new physics is claimed. The implementation is intended as a reference framework for independent verification, reproducibility and future methodological extensions.
